# 实训学时合规与冻结服务

该服务汇聚学员签到、导师确认和请假修正事件，按培养方案与时区重放学时状态，并保存可追溯的学期冻结快照。项目还提供导师分配、证明材料、豁免复核、规则版本、名额、通知和数据留存等领域模块，供后续业务扩展时复用统一的状态与审计约束。

## 分阶段培养（阶段门槛 / 结转 / 补偿 / 关账）

培养方案可发布不可变的阶段规则版本：每个阶段按业务时间（培养方案时区的学术日）划定边界，独立配置总学时门槛、类别学时门槛、结转到下一阶段的学时上限，以及类别间的补偿关系（`rate_milli` 为千分折算率）。

- 重放严格按事件的**业务时间**（签到 `check_in_at`、请假修正 `business_date`、导师确认跟随目标签到）分配阶段；跨阶段边界的签到会按学术日切段归入对应阶段。
- 上一阶段的盈余在 `carryover_cap_seconds` 封顶后结转下一阶段，超出部分计入 `spillover_lost_seconds`；学生进度返回每阶段的总量缺口、类别缺口、补偿明细与可结转来源。
- 阶段按顺序**关账（冻结）**：关账凭证不可变，迟到事件可更新未冻结阶段，但重放时剪掉关账段，不能穿透已关账边界，也不能改动关账阶段注入下游的结转量。
- 规则发布新版本后，旧关账凭证保留可查，但需按新版本重新顺序关账。

主要接口：

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| PUT | `/api/plans/{pv}/stage-rules` | 发布不可变新阶段规则版本（版本号自增） |
| GET | `/api/plans/{pv}/stage-rules` | 列出全部规则版本 |
| GET | `/api/plans/{pv}/students/{sid}/stage-progress` | 学生分阶段进度（缺口、补偿、结转来源），支持 `?rules_version=` |
| GET | `/api/plans/{pv}/stage-warnings` | 批量预警未达标且未关账的阶段，支持 `?stage_id=` |
| POST | `/api/plans/{pv}/stage-freezes/{stage_id}` | 顺序关账某阶段（幂等；前置未关账返回 409） |

阶段规则生效后，请假修正事件必须携带 `business_date`（或 `occurred_at`），否则无法按业务时间归属而被拒绝；事件负载可用 `category` 字段区分类别（缺省取 `activity_type`/`regular`）。

## 运行方式

默认数据保存在项目目录的 SQLite 文件中。安装依赖后执行 `uvicorn app.main:app --host 127.0.0.1 --port 8000`，健康检查地址为 `/health`，业务接口位于 `/api`。

python3 -m pytest -q
